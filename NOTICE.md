## Working Title

The current working title is **Checkers + Hex**.

## Project Status

This is an evolving playable prototype and design exploration. Rules, interface details, balance, and presentation may change through playtesting.

## Design Attribution

This project is an original hybrid abstract strategy game design inspired by public-domain board game traditions, including Checkers/Draughts-style jump capture and Hex-style connection gameplay.
